
# Day 13 - Aggregate Functions in SQL Server

## Topics Covered
- MAX()
- MIN()
- AVG()
- COUNT()
- DISTINCT
- Aggregate functions

## Summary

Practiced aggregate functions in SQL Server to calculate maximum, minimum, and average values and count records in a table.

## Key Takeaways
- MAX() returns the highest value.
- MIN() returns the lowest value.
- AVG() calculates the average.
- COUNT(column) counts non-NULL values.
- COUNT(*) counts all rows.
- COUNT(DISTINCT column) counts unique non-NULL values.
- Aggregate functions generally ignore NULL values.
