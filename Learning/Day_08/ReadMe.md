# Day 08 - String and Date Functions

## Topics Covered
- REPLACE()
- TRANSLATE()
- DATEPART()
- DATENAME()
- DATEADD()

## Summary

Practiced SQL Server string functions and date functions for text manipulation, date extraction, and date calculations.

## Key Takeaways
- REPLACE() replaces string patterns.
- TRANSLATE() replaces individual characters.
- DATEPART() returns numeric date parts.
- DATENAME() returns textual date parts.
- DATEADD() calculates a new date/time value.
- Date-range filtering can improve index usage when a suitable index exists.
