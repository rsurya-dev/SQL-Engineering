# Day 01 - SQL Fundamentals

## Objective

Today's goal was to get comfortable with the basics of SQL Server by creating tables, inserting records, understanding constraints, and retrieving filtered data.

Rather than memorizing syntax, I focused on understanding why each command is used and how it affects the data stored inside a database.

---

## Topics Covered

- CREATE TABLE
- INSERT INTO
- PRIMARY KEY
- NULL Values
- DATE Datatype
- SELECT Statement
- WHERE Clause
- Comparison Operators

---


## Key Takeaways

- Created my first tables using SQL.
- Inserted both single and multiple records.
- Understood how Primary Keys prevent duplicate records.
- Learned how SQL Server handles DATE values.
- Practiced filtering records using the WHERE clause.
- Explored different ways of working with NULL values.
