# Day 10 - Data Type Conversion

## Topics Covered
- CAST()
- TRY_CAST()
- CONVERT()
- TRY_CONVERT()
- Converting text to MONEY and DATE

## Summary

Practiced converting values between data types in SQL Server and handling conversion failures while working with sales data.

## Key Takeaways
- CAST() and CONVERT() perform data type conversions.
- TRY_CAST() and TRY_CONVERT() return NULL for most failed conversions.
- CONVERT() supports style codes for interpreting date strings.
- Validate converted values before updating stored data.
