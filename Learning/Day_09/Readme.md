# Day 09 - Date and Numeric Functions

## Topics Covered
- DATEADD() and DATEDIFF()
- CAST()
- Date filtering
- Integer and decimal division
- Modulus operator (%)
- ROUND(), CEILING(), FLOOR()
- DECIMAL data type

## Summary

Practiced SQL Server date calculations, type conversion, arithmetic operations, rounding, and numeric functions.

## Key Takeaways
- DATEDIFF() counts date-part boundaries crossed.
- CAST() converts values between compatible data types.
- Decimal division preserves fractional results when the expression uses decimal arithmetic.
- The modulus operator returns the remainder.
- ROUND(), CEILING(), and FLOOR() perform different rounding operations.
